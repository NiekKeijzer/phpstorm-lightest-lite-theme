# Lightest Lite: the lightest colour scheme for PhpStorm

If you need convincing of a light colour scheme, I'd like to direct you to [a post](*https://stitcher.io/blog/a-programmers-cognitive-load) on the topic. 

There is only one colour:

| Colour |
|--------|
| `#FFFFFF` |

![](screenshot.png)

## Installation

In PhpStorm, go to `Settings > Editor > Color Scheme` press the little cog next to the scheme selector, and choose `Import Scheme`. Select `Lightest_Lite.icls`.
